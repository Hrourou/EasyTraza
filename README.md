# 🥖 EasyTraza - Gestión de Lotes y Trazabilidad

**EasyTraza** es una solución de software diseñada específicamente para optimizar la gestión de inventario, el control de materias primas y la trazabilidad integral en un obrador panificador  

El sistema automatiza el registro de entradas y salidas, eliminando el papeleo diario y garantizando el cumplimiento estricto de las normativas sanitarias.

## 💻 Módulos del Sistema

### 1. Panel de Gestión Web (Oficina)
Desarrollado para el control administrativo y la toma de decisiones desde la oficina:
*   **Seguridad de Acceso:** Control de usuarios e inicio de sesión protegido.
*   **Gestión de Mi Perfil:** Configuración de datos personales y credenciales de los empleados.
*   **Recepción Avanzada:** Entrada de albaranes optimizada con soporte para lectura automática de datos mediante Inteligencia Artificial (IA).
*   **Historial de Albaranes:** Registro detallado de compras a proveedores con filtros rápidos y desglose de lotes recibidos.
*   **Gestión de Lotes:** Supervisión del estado del inventario (Lotes Recibidos, Abiertos en obrador y Acabados).
*   **Albaranes de Clientes:** Control estricto de las salidas y repartos hacia las tiendas, con bloqueo de modificaciones para albaranes ya entregados.
*   **Informes y Gráficos:** Panel visual con un gráfico dinámico evolutivo de las unidades vendidas por día.

### 📱 2. Aplicación Móvil Android (Obrador)
Diseñada con una interfaz ágil, pensada para el uso de los operarios y panaderos a pie de cañón:
*   **Login por Perfiles:** Acceso rápido y adaptado según el rol del trabajador.
*   **Dashboard Intuitivo:** Menú simplificado para agilizar las operaciones del día a día.
*   **Recepción en Planta:** Registro rápido de albaranes de proveedores seleccionando el CIF y añadiendo líneas de producto en tiempo real.
*   **Control de Consumos (Iniciar/Finalizar Lotes):** Apertura y cierre de sacos de ingredientes con un solo clic, permitiendo registrar la trazabilidad exacta y los tiempos de consumo en producción.

## 🛠️ Tecnologías Utilizadas

*   **Backend & Web:** Spring Boot, Thymeleaf, Spring Security.
*   **Mobile:** Android (Java/Kotlin).
*   **Base de Datos:** MySQL / PostgreSQL.
*   **Integraciones:** Servicios de Inteligencia Artificial para lectura de documentos (OCR / IA).
